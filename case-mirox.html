UX/UI

MIROX

SaaS для брендов

SaaSMarTechMarketplace

Задача

Цель проекта

Спроектировать веб‑платформу для брендов и креаторов с адаптацией под desktop, mobile и iPad: объединить брифинг, AI‑скоринг/подбор, модерацию контента, отчётность и постоплату в единый прозрачный процесс. Подход к таким проектам описан на странице UX/UI-дизайна сложных цифровых продуктов.

Что сделано

Решение

  • Спроектировали role‑based UX для трёх ролей: бренд, креатор, админ/команда.
  • Собрали главный workflow бренда: бриф -> AI‑подбор креаторов -> согласование ТЗ -> публикация -> отчёт -> постоплата.
  • Спроектировали workflow креатора: скоринг/онбординг -> задачи -> сдача контента -> модерация -> выплата.
  • Продумал кабинеты, уведомления, чат с маркетологом и историю кампаний.
  • Собрали логику аналитики и логов: статусы, успешные/ошибочные запросы, отчёты по API и модулям.
  • Подготовили UI‑систему и прототипы для адаптивов (desktop / mobile / iPad).

Результаты

Метрики

Единый сценарий: бриф → креатив → модерация → запуск → отчёт.
Статусы кампании видны бренду и креатору без ручных обходов.
Модерация и оплата собраны в одном рабочем контуре.
Интерфейс рассчитан на быстрый повторный запуск кампаний.

Процесс

Как работали над проектом

Контекст

Какую продуктовую задачу решал MIROX

Брендам и креаторам приходилось собирать рекламные интеграции через разрозненные инструменты: брифы отдельно, согласования отдельно, отчёты и оплаты отдельно. Это создавало потери на каждом этапе и снижало предсказуемость результата. Цель MIROX — собрать весь цикл кампании в одной SaaS‑среде.

Исследование

На чем построили UX‑архитектуру

Разложили сценарии по ролям: бренд, креатор, админ. Для бренда критичны скорость запуска и прозрачность этапов, для креатора — понятные задачи и быстрый цикл сдачи/модерации, для админа — контроль качества и поддержка. На этой основе собрали role‑based навигацию и приоритеты интерфейса.

Решения

Какие ключевые механики спроектировали

Собрали сквозной workflow кампании: бриф с параметрами (бюджет, цель, ЦА, сроки), AI‑скоринг и подбор креаторов, согласование ТЗ, публикация и модерация видео, отчётность по результатам и постоплата. Дополнительно внедрили уведомления, чат с маркетологом, историю кампаний и блоки логов/аналитики для контроля системы.

Показатели

Какой эффект дал новый дизайн MIROX

Платформа стала работать как единый операционный контур вместо набора разрозненных экранов. Пользователи быстрее проходят этапы кампании, команды лучше видят текущий статус и меньше теряют контекст между ролями. Это повысило управляемость процесса и подготовило продукт к масштабированию MVP.
